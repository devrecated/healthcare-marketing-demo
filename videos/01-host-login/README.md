# 01 — Host login

## Goal

Open the laptop demo as Acme Healthcare and land on the Clinic board.

## Surface

- Host console: https://healthcare-demo.devrecated.com/login  
- Desktop browser, full window.

## Shot list

1. Cold load of the login page — Acme Healthcare wordmark visible.
2. Show prefilled demo email `amara.okonkwo@acme.clinic` and password hint `acme`.
3. Enter password and click **Enter console**.
4. Hold on **Clinic board** overview (patients / visits / stock stats).

## On-screen copy to capture

- “Acme Healthcare”
- “Clinic board”

## Do not show

- Browser bookmarks or other client tabs.
- `.env` files, DevTools network with keys, or GitHub issues.
